# Earth imagery

These Earth color, normal, specular, city-light and cloud textures are vendored from the Three.js r180 example assets:
https://github.com/mrdoob/three.js/tree/r180/examples/textures/planets

The images illustrate Earth, not live satellite observations or facility data.
See the upstream project for asset credits and licensing:
https://github.com/mrdoob/three.js/blob/r180/LICENSE

The files are served locally to avoid runtime dependencies on third-party texture hosts.
